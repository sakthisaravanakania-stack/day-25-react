# 🌟 Day 25 - React User Card Component

A simple and responsive *React.js User Card project* built as part of my React learning journey 🚀💻

## ✨ About The Project

This project demonstrates how to create *reusable React components* and pass data between components using *Props*.

Each user is displayed inside a beautiful card containing:

👤 User Name  
📧 Email Address  
🔘 Custom Button  

The project is also made *responsive* for different screen sizes 📱💻🖥️

## 🛠️ Technologies Used

- ⚛️ React.js
- 🎨 CSS3
- 🧩 JSX
- 📦 Vite
- 💻 VS Code
- 🔧 Git & GitHub

## 📚 React Concepts Practiced

- 🔄 Reusable Components
- 📦 Props

- 🧩 Component Composition
- 🎨 CSS Styling
- 📱 Responsive Design
